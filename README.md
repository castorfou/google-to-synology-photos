# Google to Synology photos

`g2s` turns a Google Photos Takeout Export into a private NAS Library in Synology Photos, with its Albums, Captions, Comments and Likes.

Follow the [user guide](https://castorfou.github.io/google-to-synology-photos/user/) to set it up, or read the [developer guide](https://castorfou.github.io/google-to-synology-photos/dev/) to work on it.

## pyfoundry-template

Ce projet a été instancié depuis un template.

Toutes les infos sur ce template et la façon de l'utiliser sont dans sa [documentation](https://castorfou.github.io/PyFoundry/).
